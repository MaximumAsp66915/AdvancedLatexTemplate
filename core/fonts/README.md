# Bundled fonts

Persian fonts used by the `fa` templates. `mktex` copies them into every Persian
project (`latex/fonts/`), so the project builds on any OS without installing fonts.

| Font | Files | Licence |
|------|-------|---------|
| Vazirmatn (Saber Rastikerdar) | `Vazirmatn-Regular.ttf`, `Vazirmatn-Bold.ttf` | SIL OFL 1.1, `OFL-Vazirmatn.txt` |
| HM FElmi (Hossein Movahhedian) | `HM_FElmi.ttf`, `HM_FElmiBd.ttf` | SIL OFL 1.1, `OFL-HM-FElmi.txt` |

The OFL requires each redistributed copy to keep its copyright notice and licence text:
keep the `OFL-*.txt` files next to the fonts. Do not add proprietary fonts here
(B Nazanin, B Lotus, B Zar, Times New Roman...).
